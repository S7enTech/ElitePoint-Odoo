ElitePoints Loyalty

Reward and redeem ElitePoints loyalty points, right from Odoo Point of Sale.

What it does

  • Look up a customer at checkout by phone number, email, or loyalty barcode.
  • See their live ElitePoints balance without leaving the POS screen.
  • Let the customer redeem points against the current sale.
  • Points are earned automatically on the remaining amount as soon as the order is paid — no extra step for the cashier.
  • A network hiccup never blocks a sale: failed syncs are queued and retried automatically.

Setup

  1. Install this app.
  2. Get this store's API key and secret from your ElitePoints partner dashboard — each physical store has its own.
  3. Go to Point of Sale > Configuration > Point of Sale, open the shop you want to connect, and enter them under ElitePoints Loyalty.
  4. Click Test Connection to confirm everything is wired up.
  5. Running more than one shop from this database? Repeat the last two steps for each one, using that shop's own key.
  6. Open a POS session — the ElitePoints button now appears next to your other control buttons.

Requirements

An active ElitePoints merchant account. Don't have one yet? Visit myelitepoints.com to sign up.
